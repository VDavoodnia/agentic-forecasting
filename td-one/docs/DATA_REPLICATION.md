# Data & Artifact Replication Map

> **Status: CURRENT — 2026-10-20** (preservation pass)

Every dataset, model, and produced artifact the TD-One program depends
on, classified and given a preservation or replication path. Three
classes:

- **S — Shared:** Vandad's own datasets. Never committed, never moved,
  never deleted by the agent.
- **P — Produced:** generated by the program. Archived in git as
  multipart base64 zip snapshots (the push channel is text-only) with a
  `MANIFEST.json` per snapshot, or committed directly when small. An
  artifact a committed seeded script can rebuild is **not** archived —
  the script is its preservation path (see the scale-up row).
- **D — Downloaded:** public sources. Not archived; a committed script
  re-fetches them (sizes pinned where the source is stable).

Executable half of this map: `scripts/replicate_setup.py`
(`--list` prints the step map; a full run executes the automatic
steps). Snapshot restores: `scripts/restore_dist.py <dist_dir>
--target <dir>` (decodes parts, verifies sha256 end to end).

## Restoration note (exp59–exp63)

The exp59–exp63 experiment files (Monash ladders, generalizability,
LLM-as-combiner) were lost from both the working tree and the remote
during the 2026-10-20 tree churn. On 2026-10-20 they were restored
from the Repomix preshowcase dump (`td-one-full-preshowcase.md`,
2026-10-19) and committed: `exp59_generalize.py`, `exp59_report.md`,
`exp60_tourism.py`, `exp60_tsfm_resume.py`, `exp60_report.md`,
`exp61_m3.py`, `exp61_report.md`, `exp62_m4_news.py`, `exp62_report.md`,
`exp63_llm_selector.py`, `exp63_report.md` (all Python files verified
to compile; report numbers spot-checked against `FINAL_RESULTS.md`).
The experiments' `*_results.json` files were excluded from the dump
and are unrecoverable; `exp60_tsfm.json` and `exp63_partial.jsonl`
survived locally and are committed.

## Not preserved, by design

- **LLM cache JSONs (~1.8 MB)** — never committed (standing repo rule);
  regenerable by re-running the experiments.
- **Run checkpoints and caches** — exp83 checkpoints (~2.6 MB), exp85
  per-cell rows (~9.2 MB) and world pickles (48 KB; builder committed),
  exp86 Chronos cache (2.2 MB), exp88 cache (96 KB), exp75 grids cache
  (632 KB) and per-bed results (84 KB), exp82 row intermediates
  (4.5 MB; `exp82_results.json` is committed). All regenerable from
  committed code.
- **`data/news/exp87_local/` (27 MB)** — exp87's working copies of the
  news DB and a subset embeddings file; duplicates of archived
  artifacts.
- **Repomix repo dumps** (`~/workspace/td-one-full*.md`, ~11 MB) —
  regenerable from the repo at any time; the 2026-10-19 preshowcase
  dump was the recovery source for the exp59–63 restoration above.
